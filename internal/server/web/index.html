SERVER-BLIND INBOUND FILE REQUESTS

Receive the file.
Not the plaintext.

OpaqueDrop lets anyone upload through a browser while filenames and file bytes are encrypted to a key held by the recipient. The host stores ciphertext, sizes, and timestamps—never a decryption key.

01

No uploader account

A capability link opens a focused upload page. It cannot list or retrieve submissions.

02

Recipient-held key

Generate the private key away from the server, then import only the public request bundle.

03

Verifiable receipt

A SHA-256 receipt covers the exact encrypted manifest and every ciphertext chunk stored.
